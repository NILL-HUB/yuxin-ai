# Triage 标签

这些技能使用五个规范的 triage 角色。本文件把这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库中的标签 | 含义 |
| -------------------------- | -------------- | ---- |
| `needs-triage`             | `needs-triage` | 维护者需要评估该 issue |
| `needs-info`               | `needs-info`   | 等待报告者补充更多信息 |
| `ready-for-agent`          | `ready-for-agent` | 已完整描述，可供 AFK agent 处理 |
| `ready-for-human`          | `ready-for-human` | 需要人工实现 |
| `wontfix`                  | `wontfix`      | 不会处理 |

当技能提到某个角色（例如“应用 AFK-ready triage 标签”）时，使用本表中对应的标签字符串。

如果实际使用的词汇不同，请编辑右列。
